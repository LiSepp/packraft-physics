# 这篇到底研究什么

这篇建立充气皮艇产品的比较测试方法。作者用原型测重心相关的倾斜和转弯，再用缩小的硬模型预测阻力。RPO-2并非所有指标都胜过KONA。它适合参考怎样拆分测试，不适合概括充气艇必然优于硬壳艇。

# 实际做了什么

- 实验/实测：同载荷原型倾斜、25°人工方向舵转弯；缩尺FRP模型回流水槽阻力。
- 理论模型：静水力计算、GZ曲线、Froude相似和ITTC阻力外推。
- 数值模拟：无CFD；船型静水力计算。
- 综述：无。

# 真正测量或计算的变量

- 排水量/吃水/水线尺度/湿面积；GZ及倾角、KB/KM/KG、转弯轨迹。
- 速度、阻力系数、有效马力、沉降与纵倾；原型充气压力是控制量。

# 最重要的 3～8 个发现

1. 共同重心高度假设下，KONA的计算复原臂较大；倾斜试验的实际重心结果与此不是同一比较。定位：PDF p.3，§2.3、图3；p.6，表4。
2. 同25°舵角条件下RPO-2转弯半径较小。定位：PDF p.4、6，§3.3、4.2、图9。
3. 阻力由刚性缩尺模型外推；设计速度下RPO-2较低，不能归因为充气柔性本身。定位：PDF p.5–7，表3、图10–12。

# 对 Packraft 有什么用

- 可直接参考：稳性、转向和阻力分项测试及控制载荷。
- 只能做机制类比：不同艇形会有不同指标取舍。
- 暂时不能迁移：船型排名、15 Psi使用值、白水稳性和柔性阻力。

# 最容易误用的地方

- 静水 → 白水与硬壳 → 充气迁移均受限；对照同时改变船型和结构。
- 竞速艇/高速机动艇不是试验对象，但外推速度并非packraft日常条件。
- 理想水槽 → 天然河流：25°人工舵不是划桨、edge或真实回水转向。

# 值得以后学习的概念

- GZ：重力与浮力形成复原力矩时的有效力臂。
- 缩尺外推：从小模型估计原艇表现，需要相似规则。
