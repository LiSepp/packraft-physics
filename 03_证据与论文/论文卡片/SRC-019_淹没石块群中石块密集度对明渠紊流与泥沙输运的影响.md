# 这篇到底研究什么

这篇改变水底石块的间距，看流速、紊动和泥沙估计怎样变化。作者用大涡模拟，比较没有大石块和三种阵列。部分流场与已有水槽资料对照。泥沙输运来自公式预测，没有在本篇观察沙粒移动或测船。

# 实际做了什么

- 数值模拟：Hydro3D LES、WALE亚格子模型，固定球床/球形石块；周期边界，刚盖自由滑移表面（PDF p.4–5）。
- 实验/实测：用已有实验对照一个疏阵列，并引用既有网格验证；无本篇新天然河流试验。
- 理论模型：近床剪切与泥沙输运公式；不解移动泥床。
- 综述：背景引用。

# 真正测量或计算的变量

- 石块间距/覆盖率、相对淹没度、给定平均速度；三维均值/脉动、尾流、涡量、Reynolds应力、近床剪切及象限事件。
- 不同剪切定义给出的泥沙输运预测；不是实际粒子通量。

# 最重要的 3～8 个发现

1. 流向间距从稀疏到密集会改变尾流相互干扰与近床流态，密集组不能视为许多孤立石块的简单叠加。定位：PDF p.9–11、16–17；p.26–27，图4–5。
2. 局部近床剪切分布与面积平均值不同，形状阻力和床面摩擦贡献也需区分。定位：PDF p.12–14；p.30，图8。
3. 采用局部或平均剪切的输运公式预测可相差明显；这些差值是计算方案对比，不是测得真实泥沙量的误差。定位：PDF p.14–17；p.35、39，图13、表3。

# 对 Packraft 有什么用

- 可直接参考：区分局部速度/床剪切与平均量，检查数值边界。
- 只能做机制类比：石块间距可改变水流组织。
- 暂时不能迁移：天然巨石尾流范围、表面boil、船体受力或通航危险。

# 最容易误用的地方

- 所有艇型迁移均无本篇测船支持；近床剪切不是艇旁水力。
- 理想阵列 → 天然河流：固定球体、单一H/D、周期边界；刚盖不允许真实水面波动。
- 泥沙输运预测不能写成实际床面侵蚀或船员遇险率。

# 值得以后学习的概念

- 大涡模拟：计算较大的流动结构，较小部分用模型补。
- 形状阻力：水绕过突出物产生的阻力。
- 尾流干扰：一块石头后的流影响另一块。
