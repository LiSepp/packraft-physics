# 这篇到底研究什么

这篇用系留拉力信号数划桨次数，再与视频计数比较。船被弹性绳约束在水池里，载荷传感器记录整船拉力。作者还看两种计数方法与拉力指标的关联。它不是在回水门中直接测桨叶受力。

# 实际做了什么

- 实验/实测：25 m水池30秒全力系留划桨；拉力传感器1000 Hz，视频计数，已知砝码校准（PDF p.3–4）。
- 数值模拟：无流体模拟；用信号处理算法计数。
- 理论模型：一阶导数与时间间隔阈值筛选峰；无桨叶水动力模型。
- 综述：无。

# 真正测量或计算的变量

- 绳上拉力随时间、全程/5秒窗桨数和桨频、峰值/平均拉力、冲量及按体重归一化量。
- 两种计数的均值差、相关与一致性；受试者身体特征。绳拉力不是局部桨叶力。

# 最重要的 3～8 个发现

1. 信号和视频计数的总体均值差未显著，但并非逐桨完全一致，最初5秒一致性较差。定位：PDF p.6–9，表1、图2–4。
2. 信号计数桨数与视频桨数有显著关联，桨频关联未达显著；相关和一致性需分别看。定位：PDF p.7，表1及Results。
3. 与力学指标较强的关联来自同一拉力信号计算出的桨频；这不是独立证明桨频决定力或比赛表现。定位：PDF p.7–8，Results、Discussion。

# 对 Packraft 有什么用

- 可直接参考：传感器计数要与独立视频核对，并分开相关与一致性。
- 只能做机制类比：不规则力信号中识别动作时刻。
- 暂时不能迁移：系留力数值、比赛桨频、上水门或packraft表现。

# 最容易误用的地方

- 回旋运动员在静水池测试，不能把运动员项目标签当白水测验。
- 硬壳K1 → 充气packraft：绳约束、弹性和艇底稳定措施改变动力学。
- 高速机动艇不适用；水池不是天然河流。

# 值得以后学习的概念

- 系留力：船被绳拴住时绳承受的拉力。
- 一致性：两种方法是否给出接近的数，不只看一起变化。
