# 这篇到底研究什么

这篇观察主流与侧腔循环流之间的水怎样交换。作者用粒子图像测一个水平面内的速度，再从许多瞬间中提取反复出现的涡。主流旁的界面有厚度，涡也会移动并在下游角落分裂。它提供类似回水界面的流场机制，没有放船进去测控船或倾覆。

# 实际做了什么

- 实验/实测：4.9 m长、0.3 m宽直渠，0.3 m方形侧腔；Q=0.0035 m³/s、水深0.07 m、Fr=0.2；水平PIV测u/v，30 Hz，测面z=0.05 m；ADV检查（PDF p.4–5，§II）。
- 数值模拟：未报告新CFD，未来工作提出与计算结合。
- 理论/数据模型：平均/脉动分解、频谱、POD模态重构、Γ涡识别及速度交换系数。
- 综述：背景引用。

# 真正测量或计算的变量

- 水深、流量、体积平均速度、Re/Fr；二维水平速度u/v、均值、脉动、速度梯度、混合层厚度。
- 频谱/涡传播速度、识别位置/旋转符号、POD模态能量；由横向速度估计的交换系数k。
- 未测完整三维涡量、船力、横摇力矩或被动标量浓度。

# 最重要的 3～8 个发现

1. 平均场含侧腔主循环与有宽度的剪切层，厚度先增，近下游角落又减；“回水线”不能在此画成零宽固定边界。定位：PDF p.5–7，§III、图2–5。
2. 界面横向速度有接近零均值的周期脉动，流向速度更复杂；平均值会掩盖瞬时交换。定位：PDF p.8–11，§IV、图6–9。
3. 识别出的涡沿界面传播，传播速度与当地平均水速不同；图像中结构移动不能直接等同水质点运动。定位：PDF p.11–13，图9、涡追踪讨论。
4. 接近下游角落的涡会分裂为同向旋转结构，一部分进入侧腔，另一部分沿主流向下游；不是所有涡都保持完整。定位：PDF p.12–17，图10、12、14；p.19，§VI。
5. POD脉动场中的交替旋转结构不能与平均侧腔主循环的旋向混为一谈。定位：PDF p.12–14，模态重构与Γ识别、图10。
6. k=0.0252由速度场估计；作者仍要求与被动标量输运比较，不能当实际污染物停留率或艇员滞留率。定位：PDF p.18–19，§V、式4–6、图15。

# 对 Packraft 有什么用

- 可直接参考：区分平均流场、瞬时场、结构传播和水质点运动的测量思路。
- 只能做机制类比：天然回水界面可能有有限厚度、移动涡和局部交换。
- 暂时不能迁移：精确频率/厚度/交换系数、抬哪侧船边、翻船方向或通行安全。

# 最容易误用的地方

- 静水艇 → 白水、硬壳 → 充气、竞速 → packraft：本篇没有艇，不能补出船的受力结论。
- 高速机动艇 → 人力艇：无艇推进研究。
- 理想水槽 → 天然河流：规则方腔、平底、单一低Fr、无明显驻波；岩石、深浅、斜岸和三维流未覆盖。
- 不能把水平二维旋转当hole纵向滚流或boil上涌。

# 值得以后学习的概念

- 混合层：速度不同的水相遇时形成的一段过渡区。
- 相干结构：紊流中可反复识别的组织形态。
- POD：找出数据里较主要的共同变化模式。
- 涡传播速度：涡形态向下游移动的速度。
- 脉动场：从瞬时速度中减去平均速度剩下的变化。

- CANDIDATE-CLAIM：工程近似/机制类比：天然回水界面宜考虑有限厚度与瞬时速度变化，具体结构需现场核实。

  - 定位：PDF p.5–7、18–19；规则侧腔到天然河流未验证。

# 不确定或需要进一步核实

- 只测z/h约0.71的水平面；垂向结构和自由面耦合留待未来研究。

- 内腔小涡来源仍有假设；POD与阈值识别依赖处理选择。
