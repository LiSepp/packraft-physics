# 这篇到底研究什么

这篇比较三种不同结构和船底的充气皮艇。它把复原能力、实际重心、转弯和直行阻力分别测算。结果没有出现一条艇所有项目都最优。研究仍是产品水槽比较，不能直接代表短宽背包船在白水中的表现。

# 实际做了什么

- 实验/实测：原型倾斜和共同25°舵角转弯；三种FRP缩尺艇回流水槽阻力测试，原型充气压力控制15 Psi。
- 理论模型：Maxsurf静水力/GZ计算；Froude相似、ITTC模型到原型阻力外推。
- 数值模拟：无三维流场CFD，静水力船型计算不等于水弹性模拟。
- 综述：无；同系列方法见 [SRC-006](SRC-006_充气皮艇开发的水动力性能评价方法.md)、[SRC-007](SRC-007_充气皮艇开发的水动力性能评价.md)。

# 真正测量或计算的变量

- 船质量、排水量、吃水、水线宽长、湿/水面面积、形状系数与浮心；GZ对倾角。
- 倾斜时移动砝码质量/距离/角度，KG等稳性量；转弯轨迹与侧滑。
- 速度、总/摩擦阻力系数、外推总阻力/有效马力、沉降/纵倾。

# 最重要的 3～8 个发现

1. 三艇按艇重加80 kg乘员采用不同总载荷，不是三艇完全等排水量试验。定位：PDF p.5，表4、§2.3。
2. 复原臂取值角度与最大值的对应待核实；正文存在角度表述冲突，暂不把具体角度或该处艇型排序当作确定结果。定位：PDF p.5、8，图7、Conclusions。
3. 倾斜试验估计Type2重心最低，Type1最高；低重心并未单独决定三个船型的GZ排序。定位：PDF p.6–7，§4.1、表6。
4. 设计速度5 knot外推阻力Type2与Type1接近，Type3更高；阻力系数和阻力N的排序不可互换。定位：PDF p.7–8，§4.3、表7、Conclusions。
5. 共同25°人工舵角的半径相近，V型略小，Type2出现侧滑；未测试划手用桨或edge转向。定位：PDF p.5、7–8，§3.3、4.2、图15。
6. 原文报告沉降和纵倾随速度变化；沉降排序、符号及滑行解释待核实，不据此确定任何艇型是否滑行或推断天然白水浪中的姿态。定位：PDF p.7–8，表8、图18。

# 对 Packraft 有什么用

- 可直接参考：分项比较方法、核对载荷、用GZ曲线而非一个“稳”字描述。
- 只能做机制类比：艇形与重心共同影响稳性，阻力与转向存在取舍。
- 暂时不能迁移：哪种船底最适合packraft、具体GZ/阻力、充气压力和白水安全排名。

# 最容易误用的地方

- 静水艇 → 白水：复原臂是静态计算，不包含流动压强、冲击、划手支撑。
- 硬壳 → 充气：虽然原型充气，阻力试验是刚性FRP缩尺艇，不测软艇变形效应。
- 长充气艇/竞速艇 → packraft：艇形、载荷、座位和长度不同。
- 高速机动艇 → 人力艇：本篇不是机动艇；5 knot仅该试验速度。
- 理想水槽 → 天然河流：舵角、静水力和均匀来流不能给出固定翻船方向。

# 值得以后学习的概念

- 复原臂曲线：倾斜角变化时，重浮力的力臂怎样变化。
- 重心高度：整体重量作用点离船底多高。
- 侧滑：转弯时还在横向滑动。
- 阻力系数：按速度和面积归一化后的量，不等于阻力本身。
