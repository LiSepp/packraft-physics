# 这篇到底研究什么

这篇追查一次高流量中Crystal Rapid为何出现很大的驻立浪。作者结合河段照片、现场观察、附近测站资料和划手视频，再用简化水跃模型解释。论文区分岩石附近的浪和河道收缩产生的水跃。它也讨论洪水如何改变河床，但其中一部分是模型重建和解释，不能当今日通航指南。

# 实际做了什么

- 实测/观察：现场照片、观察记录、河段几何描述；附近Bright Angel测站水深/流量资料；3名划手视频用于估算艇运动（PDF p.4–11）。
- 实验：没有控制水槽试验。
- 数值模拟：简化方程计算水深、临界状态、浪的位置与能量变化，非三维CFD。
- 理论模型：矩形断面浅水、质量/能量/动量关系；河床演化与古洪水解释。
- 综述：背景引用。

# 真正测量或计算的变量

- 流量/水位、宽度与有效收缩比、附近断面深度/速度/面积；照片/观察推定的波高与位置、视频艇位/艇速。
- 模型：单位宽度流量、比能、Fr、上/下游水深、共轭水深、水跃位置及能量损失；几何改变与古洪水流量推算。
- 波高、河底形状和水流速度不全是当地直接仪器测量。

# 最重要的 3～8 个发现

1. 1983年的大normal wave与岩石附近Crystal Hole、Pour-over等现象不同；文中认为主通道无必要的突降也可由收缩产生水跃。定位：PDF p.7、9–11，图5、7及Waves of Crystal Rapid。
2. 不同来源的几何和水深各有局限：理想有效收缩比与照片宽度比并非同一量，水深主要借附近测站。定位：PDF p.4、9、12–14，表1、几何假设。
3. 3名划手影片显示艇在大浪处减速，但艇速不是水流测速，行为不能证明统一滞留或翻船方向。定位：PDF p.9，Data for Hydraulics。
4. 矩形浅水模型将上游超临界流、下游条件及共轭水深联系，预测水跃位置随流量改变；这些是模型输出。定位：PDF p.11–15，General Analysis、式1–10、图9。
5. 固定几何下的模型位置变化与观察作比较；更高流量时几何侵蚀可能改变浪的响应，不能写成波高必随流量单调增大。定位：PDF p.14–16，图9、Results及几何改变讨论。
6. 作者据水力估计讨论碎屑扇侵蚀及古洪水规模，属于解释/重建，非直接测到该古洪水或连续测到巨石位移。定位：PDF p.16–22，Geomorphic Evolution、Summary。

# 对 Packraft 有什么用

- 可直接参考：天然急流案例中区分观察、代理数据和模型的方法；辨识不同造浪几何。
- 只能做机制类比：收缩、上游比能和尾水共同影响驻立水跃。
- 暂时不能迁移：1983年流量阈值/路线到当前河段或任意packraft安全判断；古洪水计算。

# 最容易误用的地方

- 静水 → 白水：本篇是天然急流，但不提供艇体静水/白水对照。
- 硬壳艇/竞速艇 → 充气packraft：视频艇运动不等于背包船受力测试。
- 高速机动艇 → 人力艇：无这种对照。
- 理想模型 → 天然河流：真实断面、非均匀底床和侵蚀不完全满足矩形固定几何。
- 不把normal wave、岩石hole和侧向Pour-over合并成一种固定危险规则。

# 值得以后学习的概念

- 水跃：快速浅流向较慢深流转变的一段水力变化。
- 比能：相对河床看水深和流速共同占用的能量。
- 共轭水深：特定简化水跃模型中动量关系配对的两种水深。
- 尾水：下游水深条件，会影响上游水跃能否站住。
- 代理测量：用能取得的另一种量间接了解目标量。

# 可以支持哪些候选 claims

支持类型相对于下述限定主张：直接不代表直接适用于packraft，也不代表已核实。实验观察不升格为物理定律；模型预测按工程近似；迁移机制假设与经验说法保持未经充分验证。

- CANDIDATE-CLAIM：天然河流案例观察/工程解释：Crystal Rapid 1983年大normal wave可由河道收缩的水跃模型解释，并不要求主通道有离散河床跌坎。
  - 支持类型：直接
  - 定位：PDF p.7、9–14，图5、7、9、General Analysis；仅此历史案例及简化解释。

- CANDIDATE-CLAIM：工程近似：流量改变时驻立浪响应取决于几何和尾水，固定几何预测不宜外推到已侵蚀的河道。
  - 支持类型：间接
  - 定位：PDF p.14–16，图9与侵蚀讨论；不是所有天然急流的定量验证。
