# 这篇到底研究什么

这篇是同团队的研究路线讨论；索引将其列为较早年份，出版日期仍待确认。它拆分充气救生艇的整体弯扭、软底滑行和水面冲击，还讨论波浪喷溅与噪声。它主要说应该怎样研究，而不是给出完整的新验证结果。柔性机制主体可交叉读 SRC-009；不据未确认日期断定两篇出版先后。

# 真正测量或计算的变量

- 文献/拟研究变量：材料刚度、接头刚度、内压、膜张力、变形、艇速、波浪、升沉/纵倾、冲击载荷与加速度。
- 环境部分讨论波浪/喷溅以及空气和水下噪声；不把这些列为本篇已经全部实测。

# 最重要的 3～8 个发现

1. 摘要把柔性收益明确放在经验反馈和待验证目标中。定位：PDF p.1–2，Abstract、Aims。
2. 结构分解说明管、甲板接头、软底各有变形路径，并给出未来实验和计算方法。定位：PDF p.2–7，图1、§4–6。
3. 结论仍要求验证软管吸收冲击与柔性滑行性能；不是完成证明。定位：PDF p.9，§9。

# 对 Packraft 有什么用

- 可直接参考：早期项目如何拆分可研究问题。
- 只能做机制类比：软结构与水相互作用。
- 暂时不能迁移：滑行艇性能/振动健康/噪声指标到packraft。

# 最容易误用的地方

- 高速机动艇 → 人力packraft是主要越界；静水/海浪 → 白水也未测试。
- 硬壳与柔性建模差异不能省略；无竞速背包船数据。
- 理想冲击试验提议不是天然河流结论。

# 值得以后学习的概念

- 耦合研究：结构变化和水力变化要一起看。
- 待验证方案：提出怎么测试，还不等于有结果。
