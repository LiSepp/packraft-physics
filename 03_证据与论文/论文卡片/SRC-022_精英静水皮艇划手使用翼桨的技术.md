# 这篇到底研究什么

这篇用双相机比较少量优秀划手的动作。作者重建桨尖和关节轨迹，并区分相对岸边与相对艇的运动。过去比赛成绩较好者的路径有一些共同特点。论文没有直接测升力、阻力或训练因果效果。

# 实际做了什么

- 实验/实测：自选加速距离后高速通过拍摄区，两台100 fps相机；每人计划5次，筛后多数4次、S2仅1次（PDF p.3）。
- 数值模拟：影像坐标处理，无流体模拟。
- 理论模型：参考系定义、回归/相关；升力解释是推测。
- 综述：背景引用。

# 真正测量或计算的变量

- 艇速、桨频、入水/滑行时间和距离、前/后伸距、外部参考系桨尖后移slip；桨尖及肩/肘/手轨迹。
- 本研究过去比赛成功程度与短拍摄区平均艇速不是同一表现指标。

# 最重要的 3～8 个发现

1. 桨尖相对艇的路径与相对外部参考系的路径不同，slip按外部参考系纵向位移定义。定位：PDF p.4–5，Frames of Reference与变量定义。
2. 较成功者有较一致路径，更靠前/靠艇轴入桨并有较大侧移；“因此升力更优”是未测力的解释。定位：PDF p.17–18，Summary；轨迹图3–4。
3. Results指出过去最成功者并未取得最高短程平均艇速，而Summary又概括他们艇速较高；保留这处内文张力，不合成为因果结论。定位：PDF p.5，Velocity；p.17–18，Summary。

# 对 Packraft 有什么用

- 可直接参考：两种参考系、轨迹和slip的定义。
- 只能做机制类比：同一桨运动从艇上与岸上看不同。
- 暂时不能迁移：翼桨动作排名、升力优势和竞速路径到白水packraft。

# 最容易误用的地方

- 静水/硬壳竞速 → 白水充气packraft：目标、坐姿、桨型和来流不同。
- 高速机动艇不适用；短拍摄区不是完整比赛或天然急流。
- 速度变化不直接测出桨叶升/阻力分量。

# 值得以后学习的概念

- 参考系：说位移前先说明相对谁。
- slip：本文中桨尖相对外部参考系的纵向后移。
