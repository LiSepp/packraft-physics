# 这篇到底研究什么

这篇尝试从桨力预测艇速怎样变化。作者让两名划手做停止划桨减速、静止起步和逐步加速的50米测试。先从减速估计阻力，再把测到的桨力放进运动方程。它把艇形、力和节奏联起来，但验证范围只有两个人的静水工况。

# 实际做了什么

- 实验/实测：纯减速、静止起步、逐渐加速10×50 m；桨轴应变100 Hz测力、岸上视频60 fps测位移/角度；艇内另有惯性传感器（§2–5）。
- 数值模拟：运动常微分方程数值积分；不是三维CFD。
- 理论模型：一维牛顿方程、平方阻力、椭球附加质量近似、主动阻力修正K、周期平均模型。
- 综述：背景引用。

# 真正测量或计算的变量

- 人艇质量、艇长/宽、桨尺度；桨力F(t)、桨角、视频位置和艇速、周期/入水/恢复时间、平均投影推进力。
- 从数据与模型得到：有效质量、阻力面积SC_D、主动阻力系数K、推进路径长度L_p、速度与周期频率关系；附录计算摩擦/波/空气阻力。

# 最重要的 3～8 个发现

1. 无桨入水的减速试验与近似恒定阻力面积、平方速度阻力的解析解相符；阻力面积是拟合推断，不是直接拖曳力测量。定位：PDF p.5–6，式4–5、图6、§3.3。
2. 有效质量包含附加质量，但附加质量由椭球近似估计；不能把这部分当直接测量。定位：PDF p.6，§3.2、图7。
3. 桨法向力需按桨角投影才能进入前进方程；测力峰值不等于前进推力。定位：PDF p.7、9–10，图8、式6。
4. 起步拟合用K=1.25和1.10提高两名划手的阻力，能改善速度预测；K是汇总修正，不证明某一种摆动单独造成全部增阻。定位：PDF p.10、14，图12、Conclusions。
5. 逐渐加速测试显示两名划手的平均艇速与周期频率呈约三分之一次方关系；其解释依赖平均投影力近似不变和推进时长随速度变化。定位：PDF p.11–13，图14–15、式9–12。
6. 附录分别估计三种阻力，并与减速推断值比较；相符程度依赖船型近似，比例随两条艇改变。定位：PDF p.14–17，附录A、表A1。

# 对 Packraft 有什么用

- 可直接参考：纯减速/起步/分档速度三种测试怎样分离参数；明确频率定义。
- 只能做机制类比：人艇加速度由推进力和阻力之差决定、桨力方向投影和主动阻力。
- 暂时不能迁移：K、附加质量、阻力面积及速度频率指数的具体值。

# 最容易误用的地方

- 静水艇 → 白水：小封闭湖中水流被视为可忽略，白水必须处理相对水速度和空间变化。
- 硬壳/竞速 → 充气packraft：椭球形状和细长艇阻力近似不可照搬。
- 高速机动艇 → 人力艇：非本篇对象。
- 理想模型 → 天然河流：一维前进方程不覆盖横向流、转动和柔性耦合。
- 这里f按同一桨叶一次入水到下一次入水定义一个左右周期；不能直接当单侧桨次/秒。

# 值得以后学习的概念

- 力的投影：只取沿艇前进方向的那部分力。
- 主动阻力：划桨运动期间相对纯滑行增加的模型阻力。
- 阻力面积：把形状和阻力系数合在一起的拟合量。
- 有效质量：人艇质量加上需要带动的水惯性。
