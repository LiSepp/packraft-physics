# 这篇到底研究什么

这篇研究河道突然变宽后，主流与旁边回流之间的过渡区。作者改变水深和床面条件，测平均流速与速度波动，并用照片观察涡。过渡区沿下游的增长并不一直保持一样。它与回水界面有关，但几何是规则展宽，且没有船的实验。

# 实际做了什么

- 实验/实测：8 m×0.8 m水槽，侧向挡块使流宽0.6 m突然变为0.8 m；ADV测一个水平面内u/v，30 Hz、每点180 s；水深探测与撒木屑照片（PDF p.9–11）。
- 四个工况F1–F4取自既有16工况系列，不是16个本篇完整场测验；测面z=0.4h。
- 数值模拟：本篇无新CFD，引用DNS等只作讨论。
- 理论/数据模型：平均速度归一化、混合层厚度/增长率、局部床摩擦参数、频谱与对流长度估算。
- 综述：背景引用。

# 真正测量或计算的变量

- 水深、流量、床面粗糙与分离区长度；u/v均值、脉动、速度梯度、Reynolds应力。
- 由速度定义的混合层宽度δ、增长率、局部参数S、涡频率/传播尺度；图像中水平涡的形态。
- 只在给定高度测速度，不是深度平均或完整三维船力测量。

# 最重要的 3～8 个发现

1. 分离流线、速度梯度最大位置和应力最大位置不是所有位置都重合；不能把所有“界面”当同一条线。定位：PDF p.12–14，§3；p.38–40，图5–7。
2. 厚度由两侧流速差除以最大速度梯度定义；它不等于目视泡沫带宽。定位：PDF p.14，式2；p.41，图8。
3. 多数工况上游段厚度近线性增长，浅工况后段趋于平台，深工况也可降低增长率；不支持无限匀速增宽。定位：PDF p.15–16；p.41，图8。
4. 作者用局部摩擦参数讨论，认为本实验后段增长受壁面/涡相互作用影响；不是否定床摩擦在其他浅水流中的作用。定位：PDF p.16、20–21，讨论与结论；p.42，图9。
5. 涡可随深浅条件改变大小和组织，深工况更散乱；表面示踪形态不能还原全部三维速度。定位：PDF p.17–20；p.45–46，图12–13。

# 对 Packraft 有什么用

- 可直接参考：区分混合层测量定义、平均边界与瞬时涡，以及分工况比较的方式。
- 只能做机制类比：天然回水界面厚度和涡组织受水深、河床与边界影响。
- 暂时不能迁移：确定厚度/频率、抬边动作、旋转力矩、boil和倾覆方向。

# 最容易误用的地方

- 静水艇 → 白水、硬壳 → 充气、竞速 → packraft、高速机动艇 → 人力艇：没有艇的资料。
- 理想水槽 → 天然河流：单侧直角展宽、平底/受控粗糙与自由面控制不同于岩石河岸。
- 水平涡与回流区不等于纵向hole滚流；z=0.4h测面也不能直接称表面全场。

# 值得以后学习的概念

- 分离区：水绕过几何突变后形成的旁侧回流范围。
- 混合层宽度：按速度过渡快慢计算的宽度。
- Reynolds应力：速度脉动一起变化造成的动量传递量。
- 频谱：看速度变化主要有哪些时间尺度。

# 可以支持哪些候选 claims

支持类型相对于下述限定主张：直接不代表直接适用于packraft，也不代表已核实。实验观察不升格为物理定律；模型预测按工程近似；迁移机制假设与经验说法保持未经充分验证。

- CANDIDATE-CLAIM：实验观察：突然展宽的本组浅水工况，混合层增长可在下游减慢或趋于平台，并随工况变化。
  - 支持类型：直接
  - 定位：PDF p.15–16、20–21；p.41，图8。

- CANDIDATE-CLAIM：工程近似/机制类比：天然回水界面宽度不宜预设为常数或仅由一种床摩擦参数决定。
  - 支持类型：间接
  - 定位：PDF p.14–21、图8–13；天然河流迁移未测试。
