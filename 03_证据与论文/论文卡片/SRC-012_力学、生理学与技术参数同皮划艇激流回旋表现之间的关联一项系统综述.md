# 这篇到底研究什么

这篇整理哪些指标与回旋比赛表现有关。作者从三个数据库筛选文献，再把力学、生理和技术结果分开比较。不同研究的人、测试水域和计时办法差别很大。它能帮助找到研究入口，但没有合并出一个普遍有效的训练公式。

# 实际做了什么

- 综述：系统检索PubMed、SPORTDiscus、Scopus，截至2021-09-10；125条记录筛至8项，使用PRISMA流程和质量检查表（PDF p.2–4）。
- 实验/实测：没有新受试者试验，表格汇总他人数据；部分补充结果由原作者另行提供。
- 数值模拟：无。
- 理论模型：相关指标分类，未作汇总效应量的元分析。

# 真正测量或计算的变量

- 入选研究的样本特征、测试环境、完赛时间/排名等表现指标和关联统计。
- 力学类：系留峰值/平均力、冲量、功率及力量测试。生理类：摄氧量、心率、乳酸、能量系统贡献等。技术类：桨数/桨频、路线/分段时间及技术组合。
- 每个变量只出现在部分研究中，不是一个同步全测数据集（表1–4）。

# 最重要的 3～8 个发现

1. 只有8项研究符合纳入条件；表1中样本、国家、项目和测验差异明显。定位：PDF p.3–5，筛选流程图、表1。
2. 若干系留力学指标与表现相关，但一些峰值力关联未达显著，不能概括成“力量越大回旋必越快”。定位：PDF p.6，表2；p.8，Discussion。
3. 生理指标的结论不一致，包括奖牌/非奖牌组摄氧量未必显著不同；单一指标不足以区分全部表现。定位：PDF p.7，表3；p.8–9，Discussion。
4. 技术研究数量少，赛道和测试不同；表4只能保留各研究的局部关联。定位：PDF p.8，表4。
5. 质量清单平均得分高，不消除小样本、男性样本居多、四国来源与测试异质性；没有元分析统一效应量。定位：PDF p.3–4、9，质量评价、局限。

# 对 Packraft 有什么用

- 可直接参考：表1–4可作后续找原研究的路线；关联证据分类及质量检查方法。
- 只能做机制类比：力学、生理与技术需一起评估的研究框架。
- 暂时不能迁移：某测试的阈值、训练处方、packraft回水路线或安全结论。

# 最容易误用的地方

- 静水 → 白水：入选测试既有静水也有白水，不能统称白水实测。
- 硬壳回旋/竞速 → 充气packraft：项目目标、艇形和体能要求不同。
- 高速机动艇 → 人力艇：不是本篇对象。
- 人工测验 → 天然河流：完赛关联不等于天然河流施力机制，更不指定翻船方向。

# 值得以后学习的概念

- 系统综述：按预先规则寻找和筛选研究。
- 异质性：看似同类测试实际条件不一样。
- 相关指标：能随表现一起变化，未必是改变表现的原因。
- 元分析：把可比较的研究效果合并估计，本篇没有进行。
