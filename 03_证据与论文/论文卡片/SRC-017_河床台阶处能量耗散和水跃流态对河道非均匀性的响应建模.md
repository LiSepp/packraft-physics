# 这篇到底研究什么

这篇问河道收缩或展宽会怎样改变台阶后的水跃。作者把上游、台阶和下游条件连成计算模型，再批量改变水力几何参数。模型输出流态类别和能量损失。它不是天然河段的新测验，预测范围仍受二维水跃经验条件限制。

# 实际做了什么

- 理论模型：质量、能量关系与水力几何幂律；将既有堰流水跃流态阈值用于河床台阶。
- 数值模拟：Excel参数计算，不是三维流体CFD；批量改变几何、水深/速度关系和台阶高度。
- 实验/实测：没有本篇的新验证数据，p.11–12明确模型缺覆盖参数范围的数据。
- 综述：选择性回顾。

# 真正测量或计算的变量

- 流量、宽度/深度/速度的幂律系数与指数、台阶高度、上下游比能和Fr、无量纲落差/水深比。
- 输出：流态分类、全控制体能量损失hL及归一化值；不是直接测量的气泡或船体力。

# 最重要的 3～8 个发现

1. 连续性使上下游宽度、水深和速度不能随意独立指定；模型的几何参数受到约束。定位：PDF p.4–7，§2、相关守恒式及水力几何。
2. hL代表全控制体损失，淹没情形难把它单独归给水跃；不可称为局部hole耗能测量。定位：PDF p.5，段落[15]与能量方程。
3. 水跃流态边界来自已有二维堰流经验，部分界限带主观划分，standing wave等也非独立精确界定。定位：PDF p.10–11，§2.4、图9、式15–18。
4. 改变上下游水力几何会改变模型流态及耗能；展宽与收缩不能只看台阶高度判断。定位：PDF p.13–20，图11起的流态/能量参数结果。
5. 模型对较高流量、较低台阶可更受非均匀几何影响；结论限定本文参数关系，未验证所有天然河段。定位：PDF p.20–23，Discussion、Conclusion。
6. 作者承认缺少足够数据验证，并讨论经验阈值与天然台阶粗糙/不规则条件差异。定位：PDF p.11–12，段落[40]；p.23，§4.4。

# 对 Packraft 有什么用

- 可直接参考：把上游条件、台阶与尾水共同列入模型输入，以及识别耗能控制体。
- 只能做机制类比：不同河道几何会改变水跃能否露出水面或淹没的可能条件。
- 暂时不能迁移：模型流态阈值、侵蚀量和packraft安全等级。

# 最容易误用的地方

- 静水艇 → 白水、硬壳 → 充气、竞速 → packraft、高速机动艇 → 人力艇：没有任何艇体或控船实验。
- 理想化模型 → 天然河流：经验阈值多来自二维堰流，真河床有粗糙、多维与自由面变化。
- “能量损失较大”不自动等于船更易滞留；“淹没”也不自动等于安全。

# 值得以后学习的概念

- 水力几何：流量改变时宽度、水深和速度怎样一起变。
- 控制体：守恒计算选定的那段水域。
- 流态阈值：模型按某个条件把连续现象分到不同类别。
- 模型验证：用未参与设定模型的数据检查预测。
