# 这篇到底研究什么

这篇把艇体阻力、桨推进和运动员功率放进同一套预测。它先估算摩擦、波浪和空气阻力，再用桨尾涡模型估算推进效率。把平均推力与阻力配平后，可以算某种参数改变时艇速可能怎样变。主要成果是工程模型和灵敏度分析，不是新的背包船实测。

# 实际做了什么

- 实验/实测：引用已有拖曳、船型、划桨和竞赛数据，本篇未报告新的成组实验。
- 数值模拟：公式数值计算，非CFD。
- 理论模型：阻力分解、尾涡冲量/能量、效率和速度灵敏度。
- 综述：选择性回顾背景，不是系统综述。

# 真正测量或计算的变量

- 艇长/质量/排水量/湿表面积、艇速、雷诺数与弗劳德数；摩擦/造波/空气/总阻力及阻力面积。
- 桨叶面积、入水/周期时间、尾涡面积/方向/核心尺寸、推进效率、每人机械功率；参数变化对应的速度变化。

# 最重要的 3～8 个发现

1. 阻力按摩擦、波浪和空气贡献估算；K1与K4的贡献比例不同，不存在一个通用比例。定位：PDF p.2–4，The estimation…、表1。
2. 平均有效桨力须与艇阻力配平；划手总功率还含留在水中的运动能量，所以不等于阻力乘艇速。定位：PDF p.4–5，式2–5。
3. 翼桨较高效率来自尾涡面积等假设；74%和89%是模型估计，非本篇直接测出的packraft效率。定位：PDF p.5–6，式5–6、图2–3。
4. 功率对速度的约三分之一灵敏度依赖模型中阻力面积/效率处理，不能变成任何船都适用的精确指数。定位：PDF p.6–7，Sensitivity analysis、表2。
5. 表3“可能达到的参数改善”是作者主观估计，不是设计改造实验验证。定位：PDF p.6–7，表3及相邻文字。

# 对 Packraft 有什么用

- 可直接参考：记录输入、估计量和灵敏度的计算框架。
- 只能做机制类比：推进功率要同时克服艇阻力和水中能量损失。
- 暂时不能迁移：阻力占比、效率、最佳桨型和百分比性能收益。

# 最容易误用的地方

- 静水/竞速/硬壳艇 → 白水packraft：细长船体和近似定速不覆盖短宽柔性艇、转向和急流。
- 高速机动艇 → 人力艇：本篇是人力竞速，不涉及发动机滑行。
- 理想尾涡 → 天然河流：假设半圆涡环及尾涡结构，不是紊流河段全流场。

# 值得以后学习的概念

- 推进效率：划手做的功有多少最终用于克服艇的阻力。
- 尾涡冲量：桨留下的水流动量结构。
- 灵敏度：一个输入略变时模型输出变多少。

# 可以支持哪些候选 claims

支持类型相对于下述限定主张：直接不代表直接适用于packraft，也不代表已核实。实验观察不升格为物理定律；模型预测按工程近似；迁移机制假设与经验说法保持未经充分验证。

- CANDIDATE-CLAIM：工程近似：静水竞速性能预测需要区分克服艇阻力的有效功率与桨对水做功的损失。
  - 支持类型：直接
  - 定位：PDF p.4–5，式2–5。

- CANDIDATE-CLAIM：机制假设：packraft性能分析也应分别记录艇阻力与桨推进损失，系数需另测。
  - 支持类型：间接
  - 定位：PDF p.4–6；没有packraft参数。

# 不确定或需要进一步核实

- 阻力资料稀少，模型使用若干经验近似；波阻预测及艇形联动仍待精化。
- 作者明确未有直接功率实测作比较，不能把“合理数量级”当验证。
