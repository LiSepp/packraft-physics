# 项目交接

## 项目目的与权威记录

Packraft Physics Lab 服务于背包船爱好者的实际学习：理解水怎样运动、船为何平移／旋转／失稳，以及桨和身体还能控制哪些变量；用于训练、视频复盘和动作校准，未来制作 ADHD 友好的交互动画与教学视频。项目不是以完成学术论文为目标。

GitHub 公开知识库是长期知识源；私人全文资料库保存个人阅读的原文、译文、图片与历史版本。聊天过程在有价值信息进入正式文件后无需重复归档。

## 当前重点学习与以后工作方法

按[学习入口](../01_学习入口/从这里开始.md)顺序：基础物理画面 → 前划的可观察变量 → 流水控船的前置 → 复杂白水的现象与边界。完整身体动力链明显欠证据；立刃、进回水、ferry、Boof 不能由本批整理直接形成动作教程。

每次只完成一个小而可验证的目标。严格区分物理定律、工程近似、白水教学经验和未充分验证口诀；重要主张记录证据、条件、反例、可信度与教程资格。先查已有 SRC／异常／待决项，补资料或改结论需独立任务。禁止固定翻船方向，未知不补猜。

ChatGPT 主要负责研究、事实核查与教学设计；Codex 主要负责仓库文件、模拟、动画与测试。真实训练用[监测闭环](../04_训练与复盘/动作监测方案.md#推荐训练闭环)，当前没有启动动画开发或新论文检索。
