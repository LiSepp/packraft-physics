# 来源索引

资料应能被再次找到，并明确它能支持什么、不能支持什么。引用主张时使用来源编号；未查阅原文的资料须标明这一点。

每条来源复制以下模板填写：

```markdown
## S-001｜来源标题

- 类型：论文 / 教材 / 书籍 / 专业教学资料 / 厂商资料 / 网页 / 其他
- 作者或机构：
- 发表日期或版本：
- 出版信息及定位：出版方、页码或章节等；不适用则注明。
- 链接或标识：URL / DOI / ISBN；不适用则注明。
- 查阅日期及范围：是否查阅原文；查阅了哪些部分。
- 与项目的关系：可支持或质疑哪些主张（使用 `C-...` 编号）。
- 可靠性与局限：资料性质、方法或利益关系等需要注意的因素。
```
