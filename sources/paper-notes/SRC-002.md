# 这篇到底研究什么

这篇比较精英竞速划手在不同桨频下怎样施力。作者同步记录桨轴弯曲信号和艇的加速度，把每一桨的力画成随时间变化的曲线。它关心峰值之外，力能维持多久以及何时开始和结束。结果是静水短距离表现的关联，不能直接指定白水控船动作。

# 实际做了什么

- 实验/实测：同一划手完成60、80、100桨/分钟及自选比赛节奏的水上试次；桨轴应变测力、艇上加速度、计时（PDF p.2）。
- 数值模拟：无。
- 理论模型：用力矩平衡把桨轴力换算成桨叶力，假设转轴位于上手（式1）。
- 综述：无新综述；引用竞速与赛艇背景。

# 真正测量或计算的变量

- 实际桨频、试次时间和平均艇速（试程待核实，见 DISCREPANCY-002）；桨叶力时间序列、峰值力、平均力、达峰时间、每桨冲量、平均力/峰值力比。
- 入水/空中阶段时长及比例；艇加速/减速起点相对一桨的位置；运动员身体特征（表1）。

# 最重要的 3～8 个发现

1. 高桨频时平均力/峰值力比增大，曲线更接近平台形，而非真正恒定力矩形。定位：PDF p.3–4，图1、表2。
2. 跨桨频试次每桨冲量没有显著差异；不能从更高桨频推出每桨冲量必增。定位：PDF p.3，Results；p.4，表2。
3. 平均艇速与平均力、峰值力均有关联，平均力的相关更高；相关不是训练干预的因果证据。定位：PDF p.3，Results。
4. 随着桨频增加，入水和空中阶段均缩短，但入水占一桨的比例呈增加趋势。定位：PDF p.4–5，表2、图2。
5. 桨轴换算假设可能高估部分入水阶段的力；早期小峰后的下降可能与轴弹性有关，但作者未通过改变刚度验证。定位：PDF p.4–5，Discussion、式1。

# 对 Packraft 有什么用

- 可直接参考：力曲线、冲量、平均/峰值比与加速度同步的记录方法。
- 只能做机制类比：峰值相同也可能有不同的整桨发力历程。
- 暂时不能迁移：比赛桨频、快速入出水处方、矩形曲线最优性或白水动作建议。

# 最容易误用的地方

- 静水艇 → 白水：测试明确排除水流影响，白水目标还包括转向与支撑。
- 硬壳艇/竞速艇 → packraft：阻力、惯性、坐姿和桨型不同，力值/节奏不可照搬。
- 高速机动艇 → 人力艇：无此类数据。
- 理想化水域 → 天然河流：有静水与微风边界，未测紊动来流。

# 值得以后学习的概念

- 力时间曲线：一桨里力怎么起、怎么维持、怎么落。
- 每桨冲量：这一桨累计的力作用。
- 平均力/峰值力比：衡量力是短促尖峰还是较持久的平台。
