# 这篇到底研究什么

这篇看粗糙河床上是否有比水深大得多的速度变化结构。作者长时间拍摄示踪粒子，用速度频谱区分两类主要尺度。两类结构对水深的缩放表现不同。它研究均匀明渠中的紊流，不直接研究boil、回水或船的受力。

# 实际做了什么

- 实验/实测：18 m长、1.18 m宽水槽，16 mm球床；四相机立体PIV测横向竖直平面三分量速度，5工况各32组/秒连续120分钟（PDF p.3–4）。
- 数值模拟：无新CFD；从时间记录按Taylor假设重建空间尺度。
- 理论/数据模型：相关、预乘频谱、波数变换与尺度归一化。
- 综述：背景引用。

# 真正测量或计算的变量

- 水深H、流量、平均速度、床坡、粗糙尺度D、摩擦速度、Re/Fr与宽深比。
- 三分量速度、均值/方差/高阶统计、两点相关、频谱峰值、估计的流向/横向波长。

# 最重要的 3～8 个发现

1. 外层流向速度的预乘频谱有两类主要峰，对应LSM和VLSM；不是在瞬时照片中量出每个涡的完整实体长度。定位：PDF p.9–12，§3.3、图5–6。
2. LSM流向尺度按水深归一化后较一致，VLSM不纯按水深缩放；宽度、粗糙或黏性尺度的影响尚未分离。定位：PDF p.11–13，图5及结论。
3. VLSM横向尺度约在两倍水深附近，形成机制仍未解决；不同缩放只提示可能独立形成，不是证明其来源。定位：PDF p.11–13，图6、Conclusions。

# 对 Packraft 有什么用

- 可直接参考：用长记录而非短片段辨认低频流速变化的方法。
- 只能做机制类比：水流的时空波动可含多种尺度。
- 暂时不能迁移：天然河流boil尺度、船受到的力或控船规律。

# 最容易误用的地方

- 所有艇型都未测试，不能从水速度频谱补出packraft动作结论。
- 理想水槽 → 天然河流：均匀球床、Fr<1、无可见水面浪；不同于台阶、侧腔或大石块急流。
- 频谱推算波长不能称为直接测到自然河流某个涡的长度。

# 值得以后学习的概念

- 预乘频谱：看不同尺度各占多少速度波动能量。
- Taylor假设：把随时间经过测点的变化近似换成沿流向的结构。
- VLSM：比通常大涡尺度还长的速度组织。

# 不确定或需要进一步核实

- Taylor假设及对流速度可能扭曲波数估计，作者明确提醒（PDF p.9）。
- 宽度、水深比、粗糙相对尺寸等在本组不能完全独立分辨；测窗对深工况横向分辨受限。
- 旋转相关模式与平均二次流的关系仍是假设。与 [SRC-019](SRC-019.md)局部石块尾流、[SRC-014](SRC-014.md)侧腔界面不是同一流况。
