# 这篇到底研究什么

这篇沿用前一篇的水槽评价方法比较新艇。它计算静态复原能力，测重心和带舵转弯，并预测部分艇型阻力。不同项目有不同优胜艇型。英文摘要与正文的艇型对应不一致；结果段也只作原文记录，性能对应仍待核实。

# 实际做了什么

- 实验/实测：原型倾斜与25°舵角转向；RD-FK-11缩尺FRP阻力模型。
- 理论模型：Maxsurf静水力、GZ、ITTC阻力外推。
- 数值模拟：无流场CFD。
- 综述：无；方法重复见 [SRC-006](SRC-006.md)。

# 真正测量或计算的变量

- 吃水/排水量/湿面积/几何系数；复原臂、重心、倾角、带舵转弯轨迹。
- RD-FK-11和对照的阻力系数、有效马力、沉降与纵倾随速度变化。

# 最重要的 3～8 个发现

1. 统一排水量的静水力比较中KONA复原性最好、RD-FK-12最低；这是所列艇型和指定条件的结果。定位：PDF p.6，§4.1、图8。
2. RD-FK-11/12 的性能对应待核实；结果段与摘要对应有冲突，不选定某一版本。仅保留分项测试覆盖的记录，不据此确定转弯优胜艇型。定位：PDF p.6–7，§4.2–4.3、图9–11。
3. 阻力章节只把RD-FK-11与RPO-2/KONA比较，并未提供RD-FK-12的完整同等阻力测试。定位：PDF p.5–7，§3.4、4.3。

# 对 Packraft 有什么用

- 可直接参考：与前后系列交叉读取时核对艇型和测试覆盖。
- 只能做机制类比：重心低、复原能力大和转向快不是同一指标。
- 暂时不能迁移：艇型排名或白水控制效果。

# 最容易误用的地方

- 静水带舵艇 → 白水packraft不成立；硬壳/充气混合对照不能孤立材料效应。
- 非竞速/机动艇研究；实验目标速度不可自动赋给人力背包船。
- 刚性缩尺模型和理想水槽不验证天然河流或柔性水弹性。

# 值得以后学习的概念

- 指标取舍：一个艇型可能某项好、另一项差。
- 测试覆盖：先确认某个艇到底做了哪一项实验。
