# 这篇到底研究什么

这篇整理水跃和向上游传播涌波的实验认识。作者把波状水面、强烈翻滚和夹气现象分别讨论，还重新比较已有数据。它特别关注水槽缩小后哪些现象仍能相似，哪些会失真。它不测船或划手，也没有直接建立hole危险等级。

# 实际做了什么

- 综述：选择性调查实验与现场资料，表1–2汇总波状水跃研究。
- 实验/实测：重用作者及他人的水深、ADV速度、气泡探针资料；不把综述全列为本篇新实验。
- 数值模拟：无新完整CFD。
- 理论模型：矩形水跃动量关系、无量纲分析、旧数据重绘及尺度比较。

# 真正测量或计算的变量

- 文献变量：上下游水深/速度、Fr、渠宽/深比、波高/波长；涌波传播速度、局部速度脉动和剪切/紊动统计。
- 两相流：含气率C、气泡计数率F、气泡/界面尺度和时间、Re、表面张力/黏度等相似参数。
- 没有艇滞留、翻船概率或人体伤害测量。

# 最重要的 3～8 个发现

1. 波状水跃的波幅和出现范围受断面宽深比等条件影响，文献不是给出一个适用于所有河段的Fr切换值。定位：PDF p.2–5，表1–2、图3–4。
2. 驻立波状水跃与传播涌波边界条件不同，不能仅凭外观把二者互换。定位：PDF p.6，§2.3；p.8–13，正涌波资料。
3. 涌波经过时局部速度可快速减速并伴随横向脉动；这些结论来自所引用测验，天然河流的完整时空数据仍少。定位：PDF p.8–13，相关速度图及现场研究讨论。
4. 夹气、涡量及气泡扩散并非同一个量；本文用多个气泡/流体参数描述翻滚区。定位：PDF p.14–15，图14及量纲分析。
5. 仅匹配Fr并不足以保证缩尺水跃气泡特性相似；相同Fr不同Re的数据呈现不同两相统计。定位：PDF p.15–17，尺度效应图和讨论。
6. 作者要求更高Re的验证，指出小尺度资料外推真实大型水跃的限制。定位：PDF p.18，Conclusion。

# 对 Packraft 有什么用

- 可直接参考：水跃类型和实验相似性的研究检查项目；用综述查找原实验。
- 只能做机制类比：天然浪/hole中的流态转变与含气、紊动。
- 暂时不能迁移：凭白色泡沫判断回流强弱、滞留能力、安全阈值或翻船方向。

# 最容易误用的地方

- 静水艇 → 白水、硬壳 → 充气、竞速 → packraft、高速机动艇 → 人力艇：论文不含艇，不能推出对应动作效果。
- 理想水槽 → 天然河流：矩形水平渠、流量/边界层和黏性尺度限制；二维稳态方程不是三维hole全貌。
- 把含气率当力或危险程度会跳过关键证据。

# 值得以后学习的概念

- 弗劳德数：比较流速与重力波传播速度的比例。
- 雷诺数：比较惯性和黏性影响的比例。
- 波状水跃：过渡后水面以一串波表现的水跃。
- 含气率：某处水气混合物中空气占的比例。
- 尺度效应：模型缩小后有些物理比例随之改变。
