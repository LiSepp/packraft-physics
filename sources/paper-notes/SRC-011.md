# 这篇到底研究什么

这篇观察优秀划手绕过上水门时选择的路线。两台相机记录头部和艇上的标记点，比较路线与过门时间。它发现所分析弯道中头部靠内杆距离与耗时相关。它没有测回水线流场、桨力或倾侧受力，所以只提供路线表现证据。

# 实际做了什么

- 实测：每人计划6次六门赛段，分析第2个左侧上水门；碰杆试次剔除。双相机三维重建头与艇标记（PDF p.3–5）。
- 实验：标准赛道条件下重复试跑，非随机路线干预。
- 数值模拟：无流体/艇动力学模拟。
- 理论模型：轨迹指标定义、相关与组间统计。
- 综述：无。

# 真正测量或计算的变量

- 头部/艇标记三维坐标；头部从位置1到4的时间；此段头部至内杆平均距离（作者的boat trajectory指标）。
- 个体/试次平均、标准差/变异系数、相关与回归；K1/C1及最快/最慢两人比较。
- 赛道总流量14 m³/s是设施设定，非局部回水线流速测量。

# 最重要的 3～8 个发现

1. 轨迹指标是头部至内杆的平均距离，不是独立测得的艇质心、转弯半径或水流路线。定位：PDF p.5，图4及指标定义。
2. 所分析时间与轨迹指标高度正相关，单次与个体均值相关不同；仍是观察性关联。定位：PDF p.7–8，图6–7、表I。
3. 较慢组进门早期更紧，却在后续转弯更宽；不能缩成“全程越贴杆越快”。定位：PDF p.6–7，图5、Results。
4. 最快两名K1和C1策略指标无显著差异，但C1快慢组的时间差未达到显著。定位：PDF p.7–9，Results、Discussion、表II。
5. 较快者绝对时间变异较小，百分比变异并未随耗时显著改变。定位：PDF p.7–8，表I。
6. 作者指出有最优距离下限及碰杆代价，且水况、门位、艇形与推进等影响未分离。定位：PDF p.9–10，Discussion、Conclusion。

# 对 Packraft 有什么用

- 可直接参考：视频标定、重复轨迹与局部计时指标。
- 只能做机制类比：packraft进回水选线可能需要分段比较，不能只看入口距离。
- 暂时不能迁移：固定最优路线/距离、回水线施力解释、edge和翻船方向。

# 最容易误用的地方

- 静水 → 白水：本篇本来是白水，但只测运动，未测水。
- 硬壳回旋/竞速规则 → 充气packraft：船形、座位、目标与碰杆规则不同。
- 高速机动艇 → 人力艇：非此对象。
- 人工白水赛道 → 天然河流：14 m³/s总流量不能代表局部剪切层，单门不能代表所有回水。

# 值得以后学习的概念

- 轨迹代理：用便于测的头部位置代表路线，需记清定义。
- 相对变异：按均值大小归一化后的波动程度。
- 关联与因果：一起变化不说明一种变化独自造成另一种。
