# 动作监测方案

目标是帮助业余爱好者看清自己的动作、比较重复训练和校准观察；本方案整理既定设备与记录方向，不新增动作处方，也不把监测指标当成已经验证的效率或安全指标。

已有设备：DJI Action 6，可用头顶视角和船头视角；Apple Watch。以后可增加手机岸边固定机位。以下是记录优先级，不是对设备精度或应用功能的实测认证；实际可用性以拍到／导出的数据为准。

## A｜现在值得记录

视频事件较容易逐帧标注，但必须看得见对应位置：

| 项目 | 怎样记录与保留边界 |
|---|---|
| 桨叶入水、出水时刻 | 标记帧号和时间；模糊时给时间区间，不伪造精确时刻。 |
| 单次水中阶段时长 | 用出水减入水时间；不称为真实有效推力持续时间。 |
| 左右桨节奏、桨频 | 明确一桨指单侧一次入水，还是完整左右周期；记录片段长度和计数口径。 |
| 左右不对称 | 分别比较两侧时长／节奏／粗略位置；不直接判哪侧技术好。 |
| 入水、出水相对船体的大致位置 | 用船头、座位等可见参照，注明头顶／船头机位；保持“大致位置”。 |
| 桨叶是否充分浸没 | 看得到才标是／否；水花、遮挡、透视或水下不可见时标未知。 |
| 船头 yaw 明显变化 | 标明显朝向变化及机位是否随头转动；不以头部转动代替船头偏航，不据此计算真实转弯半径。 |
| 动作重复一致性 | 比较同段若干桨和历史片段；同时记录水况与遮挡，不只选最好的一桨。 |

Apple Watch 可以保留实际已经记录到的心率、训练时长、GPS 轨迹和速度；若已有可靠划艇应用并能确认计数口径，再记录桨频。本次不指定应用、不验证设备功能，也不将缺失数据补造出来。

速度必须注明参考系和环境：GPS 给的是相对岸／地面的运动；记下静水／流水、方向、风与测试条件，不能把不同条件的岸速当成同一动作效率。

## B｜可以以后尝试

| 项目 | 尝试前需要明确什么 |
|---|---|
| 岸边侧面固定机位 | 拍到船体和身体的范围、距离及参照；保留与船上机位不同的观察能力。 |
| 身体旋转角 | 先定义部位、参照平面和可见标记；二维投影不冒充三维关节角。 |
| 前伸与退出位置 | 同一机位与船体参照比较，不从像素直接输出真实三维距离。 |
| 船体 roll／pitch | 先确认可见船体参照；机位随头运动与船体运动分开。 |
| 视频与 GPS／心率同步 | 记录各自时间戳和对齐误差，保留采样间隔；未同步就不作逐桨关联。 |
| 自动动作分段 | 先用人工帧标核对，再使用自动结果；漏检和遮挡保留。 |
| 静水重复短距离测试 | 记录路线、距离、载荷、设备、风水条件及重复次数，只作个人对比。 |
| 同桨频／同心率条件下的表现对比 | 定义计数与时间窗口，记录条件和个人状态；一次差异不当成因果效果。 |

## C｜当前不值得追求研究级精度

现阶段不把时间投入单摄像头真实三维桨叶轨迹恢复、单摄像头厘米级桨叶深度、专业测力桨、船体压力传感器阵列、IMU 阵列、专业动作捕捉或 CFD 实时动作反演。这些不属于当前整理任务，也不是开始有效个人复盘的前置。

## 四条解释边界

- 心率不是动作质量；它可作为训练记录的一部分。
- GPS 岸速不是流水中的真实划桨效率。
- 桨频不是效率本身；不同计数口径先对齐再比较。
- 单一视频角度不输出伪精确三维量；运动轨迹、代理信号与真实受力分开。

相关证据边界见[证据地图](../03_证据与论文/证据地图.md)的桨频／艇速、桨控力矩与测量问题，以及[论文阅读路线](../03_证据与论文/论文阅读路线.md) SRC-002、013、021～023。运动学和生理记录不自动解决[身体传力、支撑与专项控船缺口](../02_核心知识/研究缺口.md)。

## 推荐训练闭环

理解概念 → 选 1～2 个可观察变量 → 下水拍摄 → 提取视频指标 → 与自己历史重复测试比较 → 复盘 → 再调整动作。

每次复盘写清：想观察的问题、片段／机位／时间、环境与计数口径、看得到的事实、与历史记录是否可比、仍不确定的原因，以及下一次准备复查的变量。观察与解释分开；调整动作的效果继续靠个人重复记录与逐主题证据核实，不由本文件预先指定。
