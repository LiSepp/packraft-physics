# 训练与复盘

这里用于把概念理解接到自己的训练记录：下水训练设计、DJI Action 6 视频分析、Apple Watch 数据、动作校准、每次训练复盘，以及以后模拟／教学动画带回的观察反馈。

先看[动作监测方案](动作监测方案.md)。当前先做个人观察与重复比较，已有论文不直接提供业余背包船的最优动作处方。一次只选 1～2 个可观察变量；看不清、不同步或条件不相近时保留未知，不强行给分。

开始前看[学习入口](../01_学习入口/从这里开始.md)，有疑问查[证据地图](../03_证据与论文/证据地图.md)，遇到专项未知查[研究缺口](../02_核心知识/研究缺口.md)。具体训练记录在有真实训练时再创建，不提前铺空模板目录。
