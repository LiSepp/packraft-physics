# 一句话

横滚、俯仰、偏航分别是侧倾、点头、转头。

# 我应该看到什么

同一背包船用三个视角展示：正面看左右倾斜，侧面看船头升降，俯视看船头朝向改变。每幅只突出一个转动。

# 水正在做什么

- 水对船体的作用分布可能随时间变化。
- SRC-003 分别计算三个方向的艇体力矩，即让船转动的作用。
- 该计算固定艇姿，并没有展示自由转动后的完整反馈。

# 船为什么会动

横滚（roll）绕船头到船尾的轴；俯仰（pitch）绕左右横向轴；偏航（yaw）绕上下轴。对应方向的合力矩用于解释转动变化。三者可同时出现，真实船体也可能上下、前后、左右平移；不能由一个方向的力推定全部姿态。

# 我能改变什么

- 桨叶位置、角度、力度和施力时机。
- 身体姿态。
- 船头朝向。

# 最容易想错的地方

- 船整体升高不一定是俯仰。
- 横向滑动不一定是偏航。
- 看到姿态变化，不能直接认定是哪一股水单独造成的。
