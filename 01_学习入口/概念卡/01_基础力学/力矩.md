# 一句话

力矩是力让物体转动的作用。

# 我应该看到什么

从上方看背包船旁的一次划桨。把桨的位置与船头朝向同时标出来，观察前进和转动是两个不同变化。

# 水正在做什么

- 桨改变艇旁局部水流。
- SRC-003 的固定竞速艇模型中，艇旁压力和多方向力矩随划桨变化。
- 模型里的力矩变化不是自由转动的实测结果。

# 船为什么会动

力臂是所选转轴到力的作用线的垂直距离；同样的力，作用位置与方向不同，力矩也会不同。合力矩是各项转动作用的合计。它是解释转动变化的基础量，但本批不能据此确定背包船实际转多少、向哪边转。

# 我能改变什么

- 桨叶相对船体的位置。
- 桨叶角度、运动路径与施力时机。
- 身体姿态。

# 最容易想错的地方

- 力大不等于绕所选轴的力矩大。
- 净阻力相近不等于各方向力矩相近。
- 力矩箭头不等于已验证的转动轨迹。
