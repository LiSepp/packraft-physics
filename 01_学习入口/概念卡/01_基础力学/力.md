# 一句话

力是推拉，合力是各方向推拉的合计。

# 我应该看到什么

背包船在平静水面起步。观察船速怎样变化，再看停止划桨后的滑行；“速度”包括快慢与方向。

# 水正在做什么

- 桨叶推动附近的水，水也对桨叶施力。
- 船体相对水运动时受到水的阻力，也就是水对相对运动的阻碍。
- 起步与滑行时，各项力不必相互抵消。

# 船为什么会动

合力就是把各个有方向的力合在一起。SRC-005 的一维前进模型用推进分力（沿前进方向的那部分力）减去阻力解释加速或减速。这里取“划手、桨和船”为整体理解外界受力；船单独怎样受力还涉及人与船的接触传力，不能只看桨上的一个力值。

# 我能改变什么

- 划桨力度与节奏。
- 桨叶入水位置、角度和运动路径。

# 最容易想错的地方

- 有力不等于正在加速；各个力可能抵消。
- 船仍在前进，不表示此刻仍有向前的合力。
- 桨上测得的峰值不等于整船的净推进力。
