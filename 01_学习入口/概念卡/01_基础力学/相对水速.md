# 一句话

相对水速度，是水相对于船或桨怎样运动。

# 我应该看到什么

俯视一条随水漂移的背包船。分别标出水、船和运动中的桨叶对岸速度；以船为观察者，再以桨叶为观察者看同一片水。

# 水正在做什么

- 桨叶感受到的是当地水相对于它的运动。
- 水、船和桨叶对岸的运动不能混用。
- 若当地水速不同，就需分别记录，不能只用整条河的平均水速。

# 船为什么会动

相对速度就是两个对象速度的差，要同时比较大小和方向。SRC-001 把桨叶相对来流用于受力模型；SRC-005 的静水阻力模型近似忽略水流。背包船跨不同流速区域时，仅知道对岸速度还不足以推算各处水力或力矩，即水的推拉及其转动作用。

# 我能改变什么

- 桨叶运动路径、速度与角度。
- 划桨力度与节奏。
- 船头朝向与所选路线。

# 最容易想错的地方

- 对岸移动快，不等于相对水移动快。
- 同一个相对速度不能同时代表船体和桨叶。
- 桨尖对岸后移不等于已测出它相对水的滑移。
