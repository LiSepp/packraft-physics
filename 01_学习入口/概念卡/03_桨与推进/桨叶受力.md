# 一句话

水对桨的力，要按方向分解后看推进作用。

# 我应该看到什么

背包船划手完成一次划桨。将桨叶姿态与力箭头放在一起，观察同一力怎样分成向前和其他方向的部分。

# 水正在做什么

- 桨叶改变附近水的运动。
- 桨型、角度及相对来流是桨叶受力研究中的变量。
- 桨叶开始加速时，SRC-001 的模型还考虑周围水的惯性，即水的运动状态不容易被改变。

# 船为什么会动

推进分力是桨受力中沿前进方向的那一部分；SRC-005 按桨角做这种分解。整船运动还取决于阻力（水对相对运动的阻碍）和人与船之间的传力。不能从力峰值单独推断艇速，也不能把一维前进模型当作支撑或转向动作的验证。

# 我能改变什么

- 桨叶角度、入水深度和入水位置。
- 划桨路径、力度、节奏与持续时间。

# 最容易想错的地方

- 力峰值大，不保证向前分力大。
- 桨有“抓住”的感觉，不表示桨固定在水里。
- 桨轴换算力、绳拉力和桨尖单点压力不是同一测量。
