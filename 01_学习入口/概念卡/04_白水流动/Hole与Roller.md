# 一句话

回旋流坑的翻滚区，要把表层回流与整体通流分开看。

# 我应该看到什么

背包船场景中，跌水或障碍附近有翻白的回旋流坑（hole）。用侧视示意理解 roller：水在局部翻滚回卷的区域；不凭白色面积决定该不该进入。

# 水正在做什么

- 部分含气水跃存在局部翻滚回卷区。
- 局部表层回流不能代表整段水都向上游流。
- 翻滚、夹气和速度波动是不同观察量。
- 具体天然回旋流坑的三维流场仍需另测。

# 船为什么会动

要解释船是否减速、转动或滞留，需要船体各处水力与桨力形成的合力（各方向推拉的合计）、合力矩（各项转动作用的合计）及随时间的变化。现有水跃综述和台阶模型没有背包船滞留或脱困试验；回卷示意图不提供这些结论。

# 我能改变什么

- 路线选择及是否进入该水域。
- 船头朝向。
- 桨叶位置、角度、力度与时机。
- 身体姿态。

# 最容易想错的地方

- 水平回水区涡不能直接当作侧视翻滚回卷。
- 白色泡沫或含气率不能直接换算滞留危险。
- 模型耗能大或水跃淹没，不足以判断船的通行结果。
