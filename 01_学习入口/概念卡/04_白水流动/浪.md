# 一句话

浪是水面的起伏形态，不等于水粒子的路线。

# 我应该看到什么

背包船场景里，浪峰相对岸边近似不动，泡沫却仍在移动。分别看“浪在哪里”与“水怎样运动”，不把两者合成同一速度。

# 水正在做什么

- 驻立浪指波形相对岸边近似保持位置。
- SRC-015 的历史大浪可用河道收缩水跃模型解释。
- SRC-016 区分驻立波状水跃与会传播的涌波；涌波是移动的水面突变。
- 这些来源只覆盖部分浪型，不代表所有天然浪的形成机制。

# 船为什么会动

SRC-015 记录影片中艇在大浪处减速，但没有测出船体受力分布。船速、上下运动和姿态变化分别需要合力（各方向推拉的合计）与力矩（使船转动的作用）来解释；不能由浪峰外形或单次减速反推出唯一原因、滞留能力或倾覆结果。

# 我能改变什么

- 路线选择与是否进入浪区。
- 船头朝向。
- 划桨力度、节奏与时机。
- 身体姿态。

# 最容易想错的地方

- 浪峰站住不等于水停止流动。
- 同样的水面形状不保证同样的水下速度场。
- 一个历史案例不能建立所有浪的通行规律。
