# 一句话

沸水是上涌外观，紊流是时空起伏的水流运动。

# 我应该看到什么

背包船附近水面有鼓起、散开的纹路，俗称沸水（boil）。先记录这块表面外观，再问水下速度怎样变；不要先认定原因。

# 水正在做什么

- 紊流（turbulence）指速度在时间和空间中不规则变化的流动。
- SRC-020 的粗糙床水槽速度波动包含不同尺度。
- SRC-019 的模型中，石块间距改变尾流组织；尾流是障碍后方受影响的水流。
- 上述资料没有直接验证天然水面沸水的成因。

# 船为什么会动

水流变化如何变成船的受力变化，需要船旁相对速度、压力及运动的同步资料。仅凭水面纹路或无艇水流速度谱，不能算出船的合力（各方向推拉的合计）、合力矩（各项转动作用的合计）或响应方向。“谱”只是按快慢不同的变化周期整理波动的方式，不是艇体载荷。

# 我能改变什么

- 路线选择和是否进入该水域。
- 船头朝向。
- 划桨力度、节奏与时机。
- 身体姿态。

# 最容易想错的地方

- 看见水面鼓起，不等于已确认水下涡的形状与来源。
- 石块模型采用不能起伏的水面边界，不能当沸水模拟。
- 水流波动尺度不能直接换算背包船受力或安全等级。
