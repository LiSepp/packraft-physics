# 一句话

水跃是快速浅流向较慢深流转变的水力过程。

# 我应该看到什么

背包船场景中，一段急流下游水面升高，有的呈波状，有的明显翻滚。用侧视图突出水流变化，船只作尺度参照。

# 水正在做什么

- 在简化浅水框架里，流动从超临界转向亚临界。
- 超临界指水流比浅水重力波传播更快；亚临界则更慢。
- 水跃可表现为波状起伏或含气翻滚，不能预设一种外观。
- 上游、河道几何与尾水共同约束流态；尾水就是下游水深条件。

# 船为什么会动

论文描述水深、速度和能量变化，没有测背包船载荷。要解释船的加速与姿态变化，需要动态水力、重力等合力（各方向推拉的合计）及合力矩（各项转动作用的合计）；水跃的能量损失不能直接当船的受力大小，也不能推算它能否通过。

# 我能改变什么

- 路线选择及是否进入该水域。
- 船头朝向。
- 划桨力度、节奏与时机。
- 身体姿态。

# 最容易想错的地方

- 所有驻立浪和回旋流坑（局部有回流翻滚的水域）不能都归为同一种水跃。
- 河床没有明显跌坎，不代表不可能形成水跃。
- 模型流态或耗能数值不是背包船安全等级。
