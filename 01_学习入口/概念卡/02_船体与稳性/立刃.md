# 一句话

侧倾控制，是有意识地改变船体左右倾角。

# 我应该看到什么

背包船接近主流与回水区（主流旁的回流或循环水域）之间的过渡带。把船体左右倾角与划手上身姿态分别标注，不规定应抬哪一侧。

# 水正在做什么

- 主流与回流之间可能存在有厚度的速度过渡区。
- 瞬时水流会变化，平均流场不是每一刻的水流。
- 本批无艇水槽资料没有测量侧倾控制后的船体水力。

# 船为什么会动

edge 在本卡指侧倾控制，不等于上身整体倒向一侧。静水侧倾会改变重力、浮力形成力矩（使船转动的作用）的几何关系；白水中还需船旁压力和桨力等资料。本批不能确定侧倾控制在跨线时改变哪项水力、造成多大转动或带来何种控制效果。

# 我能改变什么

- 船体左右倾角。
- 上身姿态。
- 桨叶位置、角度、力度与时机。
- 船头朝向与路线选择。

# 最容易想错的地方

- 上身倾斜与船体侧倾不是同一个量。
- 静水复原曲线不是跨回水线动作指南。
- 仅凭流向箭头不能规定抬边动作或固定翻船方向。
