# 一句话

阻尼是让运动或摆动逐渐减弱的耗能作用。

# 我应该看到什么

设想背包船被轻微扰动后左右摆动。把“摆幅随时间是否减小”作为待观察问题，与静水停止划桨后的前进减速分开。

# 水正在做什么

- 静水前进模型中的阻力（水对相对运动的阻碍）会消耗船的运动能量。
- 水中留下的流动与波也需要纳入能量分账。
- 持续变化的外来水流可能仍在输入运动能量，不能预设摆动只会衰减。

# 船为什么会动

阻尼描述耗能使运动减弱；复原力矩是把船推向原平衡姿态的转动作用，两者不是同一概念。一维阻力提供理解耗能的例子，但本批没有背包船横滚（左右侧倾）自由衰减试验，不能确定阻尼力矩、衰减速度或柔性减震效果。

# 我能改变什么

- 划桨施力、节奏与时机。
- 身体姿态。
- 出发前的载荷配置。

# 最容易想错的地方

- 静态复原能力强，不代表摆动衰减快。
- 一次滑行减速不能验证横滚阻尼。
- 船体柔软，不等于已证明更快耗能或更少人体损伤。
