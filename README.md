# Packraft Physics Lab

帮助我理解背包船在水中的运动、提升实际控船能力，并逐步建立可核实、可训练、可动画化的知识体系。

## 第一次来这里

打开[从这里开始](01_学习入口/从这里开始.md)，一次只学一个概念，再带着一个观察问题下水。
