# Packraft Physics Lab

## 项目目标

建立可靠的背包船白水力学知识体系，并逐步制作适合 ADHD 学习者理解的教学内容、交互模拟和动画。

## 目录说明

- `RESEARCH_PROTOCOL.md`：知识核实与进入教程的规则。
- `knowledge/claims.md`：待核实主张的记录模板与清单。
- `sources/index.md`：原始资料及其他来源的记录规范与索引。
- `knowledge/verified/`：已核实知识；产生首篇内容时创建。
- `teaching/`：教学脚本；产生首篇内容时创建。
- `sim/`：交互模拟；开始开发时创建。
- `animation/`：动画代码；开始制作时创建。

## 当前阶段

基础资料整理阶段 D2-E 已完成。当前内容仍属于研究与学习草稿；具体白水技术、动作效果及正式教程结论需经过逐主题 claim 核实后才能进入正式教程。
