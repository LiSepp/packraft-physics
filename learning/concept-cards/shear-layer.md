# 一句话

剪切层是相邻水流速度不同的一段过渡区。

# 我应该看到什么

背包船旁的主流与回水区（主流旁的回流或循环水域）交界处有一条泡沫带。把泡沫外观和实测速度过渡分开想，不把界面当成一根绳。

# 水正在做什么

- 规则水槽里，界面有有限厚度。
- 界面出现随时间变化的水平涡，即水在水平面内呈旋转组织的流动。
- 涡形态沿界面移动，不等于每颗水粒子走同一路径。
- 过渡宽度及涡组织随几何、水深和床面条件而变。

# 船为什么会动

要解释船的平移需合力（各方向推拉的合计），解释转动需合力矩（各项转动作用的合计）。剪切层资料只给出无艇水流的速度变化，没有同步测背包船表面压力。即使船头、船尾处水速不同，也不能由此直接确定偏航（船头转向）、侧倾或转动中心。

# 我能改变什么

- 所选路线和船头朝向。
- 划桨力度、节奏与时机。
- 船体侧倾角与身体姿态。

# 最容易想错的地方

- 泡沫带宽不等于按速度定义的剪切层厚度。
- 平均流向不等于每一刻的流向。
- 两端水速不同，不足以推出固定旋转或翻船方向。
