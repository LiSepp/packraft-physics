# 一句话

阻力是水对相对运动的阻碍作用。

# 我应该看到什么

背包船在平静水面停止划桨后继续滑行。用等时间船位点观察对水速度逐渐减小，不预设减速数值。

# 水正在做什么

- 水沿水线以下的船体表面流过。
- 艇体阻力可包含摩擦与造波等贡献。
- 各贡献比例依船型和工况而变。

# 船为什么会动

在SRC-005 的一维静水模型中，无推进时阻力使船减速。摩擦阻力是水因黏性而沿表面产生的切向作用；黏性可理解为相邻水层相对滑动时的内部阻碍。造波阻力则是船激起水面波所对应的贡献。平方速度阻力是该工况的工程近似，不是所有方向、所有背包船都适用的定律。

# 我能改变什么

- 划桨力度与节奏。
- 船头朝向和所选路线。
- 出发前载荷配置。

# 最容易想错的地方

- 对岸停止，不等于没有相对水运动或阻力。
- 总阻力不能一概称为摩擦。
- 细长竞速艇的阻力比例和系数不能直接套到背包船。
