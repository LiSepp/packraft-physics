# 一句话

附加质量把周围水对加速的影响记作额外质量。

# 我应该看到什么

背包船划手让已完全入水的桨叶开始加速。只观察启动阶段，用颜色突出桨周围被扰动的水；不画成粘在桨上的固定水块。

# 水正在做什么

- 启动桨叶时，周围水的运动也要改变。
- SRC-001 将这部分惯性影响放入桨叶受力模型；惯性就是运动状态不容易被改变。
- SRC-005 用另一种形状近似估计船体附加质量，两者不能混用。

# 船为什么会动

附加质量用一个等效质量表示水的惯性贡献；SRC-001 的启动模型把它与加速度联系，同时另算阻力，即水对相对运动的阻碍。这不表示船真的更重，也不等于多排开了一块水。背包船或桨叶的具体数值尚未直接测定。

# 我能改变什么

- 桨叶启动加速的快慢。
- 桨叶姿态、入水深度与运动方向。
- 划桨力度和时机。

# 最容易想错的地方

- 附加质量不等于增加的载荷或进水量。
- 桨叶附加质量不能直接当船体附加质量。
- 论文中的平板、椭球近似不是背包船实测值。
