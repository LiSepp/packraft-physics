# 一句话

浮心是静水向上托船的合力作用位置。

# 我应该看到什么

一条背包船在静水中水平浮着，再以另一幅画呈现它倾斜后水线以下的浸没形状。用颜色突出水线以下的部分。

# 水正在做什么

- 静水压力随深度增加；压力指水对表面的挤压。
- 水从不同方向作用在浸没表面。
- 静水近似把这些作用合成向上的浮力。

# 船为什么会动

对均匀密度静水，浮心可理解为排开水体积的几何中心，不是浮筒中心。倾斜改变浸没形状，浮心位置要随之重新计算。浮力与重力的作用线若存在水平间距，就形成相应力矩，也就是让船转动的作用；白水动态压力不能只用一个静水浮心替代。

# 我能改变什么

- 身体姿态与船体侧倾角。
- 出发前的载荷位置。

# 最容易想错的地方

- 浮心不是固定在船上的标记点。
- 向上浮力不保证任意姿态都有复原（回正）作用。
- 静水浮心不能独自解释浪中全部水动力。
