# 一句话

回水区是主流旁出现回流或循环的水域。

# 我应该看到什么

背包船停留在岸边回水区附近。看主流、回水区内部和两者界面的箭头，而不是给整个区域只贴一个“逆流”标签。

# 水正在做什么

- SRC-014 的规则侧腔平均场有主要循环。
- 界面有瞬时横向交换，即使其平均速度接近零。
- 涡是局部呈旋转组织的水流；部分界面涡在下游角落分裂后进入侧腔。
- 有限水平测面不能还原整个天然回水的三维运动。

# 船为什么会动

水流箭头用于描述水，并不直接给出船的合力，即各方向水力等推拉的合计。背包船的漂移和转动还需要船旁相对水运动、受力分布与桨力资料。本批没有把回水区流场与背包船受力同步测量，不能从平均循环图推算船的完整路线或滞留时间。

# 我能改变什么

- 路线选择、船头朝向。
- 桨叶位置、角度、力度、节奏和时机。
- 身体姿态与船体侧倾角。

# 最容易想错的地方

- 回水区不是处处同速、处处向上游。
- 平均循环与瞬时小涡不能混为同一种旋向。
- 水的交换系数不是船或人的滞留率。
