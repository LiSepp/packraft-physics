# 一句话

质心是整体质量分布的平均位置。

# 我应该看到什么

同一背包船载着划手和行李停在静水中。分别标出“船、划手和行李”的整体质心，以及船壳自身的质心，避免把两个对象混用。

# 水正在做什么

- 静水对水线以下的船体提供浮力，也就是水向上托船的合力。
- 船姿改变后，浸没形状也要重新考虑。

# 船为什么会动

重心是重力合力的作用点；在这里近似均匀的重力场中，它与质心重合。重力与浮力的作用线相对位置决定静水中相应的力矩，也就是让船转动的作用，不能只看质心高低。SRC-008 通过移动砝码的倾斜试验估计重心，不是把划手头部位置当质心。

# 我能改变什么

- 身体姿态和座位配置。
- 出发前行李的前后、左右及高低位置。

# 最容易想错的地方

- 头的位置不等于人艇整体质心。
- 不同艇形之间，重心最低不保证所有稳性指标最好。
- 静态载荷结果不能直接证明移动身体的白水动作效果。
