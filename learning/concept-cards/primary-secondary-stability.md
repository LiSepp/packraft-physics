# 一句话

初稳性看小幅侧倾，次稳性看较大侧倾的回正作用。

# 我应该看到什么

同一背包船保持相同载荷，在静水中分别呈现接近水平和较大侧倾两幅示意。比较的是复原（回正）作用，不是白水通行结果。

# 水正在做什么

- 静水压力形成浮力，即水向上托船的合力。
- 侧倾改变水线以下的浸没形状与浮力作用线。
- 不同倾角下，重力与浮力作用线的间距可能不同；这段用于计算回正力矩（使船回正的转动作用）的距离叫复原臂。

# 船为什么会动

稳性是受到倾斜后维持或恢复姿态的能力。本卡把初稳性与次稳性作为小倾角和较大倾角的教学分组，不设固定分界角。复原臂是重力、浮力形成复原力矩时的有效力臂；一整条曲线比单个角度更能描述这种变化，但不等于动态安全保证。

# 我能改变什么

- 出发前的载荷位置与座位配置。
- 身体姿态。
- 船体侧倾角。

# 最容易想错的地方

- 一个角度的复原臂不能代表整条曲线。
- 初稳性好不保证较大倾角下也同样好。
- 静水复原曲线不能直接给出白水翻船概率。
